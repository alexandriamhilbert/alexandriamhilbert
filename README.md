### Featured Project

#### [Multi-Platform Trend Velocity Radar](https://github.com/alexandriamhilbert/trend-aggregator)
An automated Python trend aggregator that pulls rising topics from zero-token sources (Wikimedia, Reddit, Hacker News) and normalizes engagement using a time-decay velocity algorithm.

* **Live Dashboard:** [View Streamlit App](https://trend-aggregator-togfpur3wsfahtdyvgzo5k.streamlit.app/)
* **Features:**
  * Time-decay velocity scoring
  * Min-Max normalization per platform (0–100 scale)
  * Automated CSV, JSON, and text reporting outputs
  * Built with Python, HTTPX, and Streamlit Cloud
